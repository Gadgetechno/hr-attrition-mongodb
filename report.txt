      * build_employee_doc(row, assignments) -> dict: Maps CSV columns to nested BSON documents.
      * build_exit_interview(emp: dict) -> dict: Generates separate exit interview documents.
      * main() -> None: Reads CSV, generates many-to-many project links, and executes insert_many.
  - Inputs: data/IBM_HR_Attrition_Enhanced.csv (1,470 rows).
  - Outputs: 1,470 employee documents, 12 project documents, 237 exit interview documents.
  - Dependencies: csv, random, datetime, pymongo.MongoClient, config

  - Purpose: Exercises and validates standard MongoDB CRUD mechanisms.

      * bson_type_demo(db): Inserts 9 BSON types and queries them using $type aggregation.
      * create_demo(db): Tests insert_one and insert_many on crud_sandbox.
      * read_demo(db): Queries employees using $gt, $in, $and, $or, $regex, sort, skip, limit.
      * update_demo(db): Tests update_one, update_many, $inc, $set, $push, upsert, find_one_and_update.
      * delete_demo(db): Tests delete_one and delete_many.

  - Inputs: Data from 'employees' and temporary 'crud_sandbox' collection.
  - Outputs: Console logs demonstrating operation outputs and modified counts.
  - Dependencies: json, datetime, decimal.Decimal, bson.Decimal128, pymongo.MongoClient, config

File: aggregations.py
  - Purpose: Demonstrates advanced aggregation pipelines on the employee dataset.
  - Key Functions:
      * attrition_by_department(employees): $group + $project + $lookup + $unwind + $sort.
      * attrition_by_level_and_tenure(employees): $group + $project + $sort.
      * overtime_impact(employees): $group + $project + $addFields + $cond.
      * income_distribution(employees): $bucket with fixed salary ranges.
      * dashboard_facet(employees): $facet executing 5 sub-pipelines simultaneously.
      * engagement_by_quarter(employees): $unwind on embedded survey array + $group.
      * top_earners(employees): $sort + $group + $push + $slice.
      * age_bands(employees): $match + $bucketAuto into 4 equal bands.
      * exit_theme_search(db): $match ($text) + $group + $sort.
  - Inputs: 'employees' and 'exit_interviews' collections.
  - Outputs: Aggregated terminal summaries for HR metrics.
  - Dependencies: pymongo.MongoClient, config

File: indexing_demo.py
  - Purpose: Profiles query execution and benchmarks MongoDB index performance.
  - Key Functions:
      * explain_find(db, coll_name, ...): Executes db.command("explain", ..., verbosity="executionStats").
      * stage_chain(plan): Traverses winning execution plan tree into an ordered string.
      * stats(res): Extracts keys_examined, docs_examined, returned count, and millisecond latency.
      * single_field_index(db): Tests range query on monthly income before/after index.
      * compound_index(db): Tests equality + sort query before/after compound index.
      * covered_query(db): Demonstrates covered query answering filters without document loading.
      * text_index(db): Demonstrates full-text indexing on comments field.
      * sort_optimization(db): Demonstrates index-backed sorting avoiding in-memory sort stages.
  - Inputs: 'employees' and 'exit_interviews' collections.
  - Outputs: Formatted before/after metrics demonstrating COLLSCAN to IXSCAN improvements.
  - Dependencies: time, pymongo.MongoClient, pymongo.TEXT, config

  - Key Functions:

      * main(): Compares RandomForestClassifier vs LogisticRegression, logs winning model
        to 'ml_models', writes predicted probabilities back via bulk_write(UpdateOne).
  - Inputs: 1,470 employee documents from MongoDB.
  - Outputs: Stored model metadata in 'ml_models', updated risk fields in 'employees'.
  - Dependencies: datetime, numpy, pandas, pymongo (MongoClient, UpdateOne), sklearn (ensemble,

  - Exact Warning Text:
      DeprecationWarning: The '__version__' attribute is deprecated and will be removed in Flask 3.2.
      Use feature detection or 'importlib.metadata.version("flask")' instead.
  - Cause:
      Invoking flask.__version__ triggers a modern deprecation warning in Flask >=3.1.
  - Recommendation:

  - Cause:
